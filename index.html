Guía de Conexión Real

Configura tu Hoja de Google Sheets

Sigue estos sencillos pasos para almacenar todas las calificaciones de tus alumnos de forma 100% automatizada utilizando Google Apps Script.

  1. 1

    Crea tu hoja de cálculo

    Crea una nueva hoja en Google Sheets. Si deseas, asígnale el nombre "Autoevaluaciones de Innovación".

  2. 2

    Abre el editor de Scripts

    En el menú superior, ve a Extensiones > Apps Script.

  3. 3

    Copia y pega el código de abajo

    Reemplaza todo el contenido del archivo Código.gs con el código que te proporcionamos a continuación.

  4. 4

    Implementa como Aplicación Web

    Haz clic en Implementar > Nueva implementación. Selecciona "Aplicación web". En "Quién tiene acceso", selecciona Cualquiera (es crucial para permitir las respuestas de tus estudiantes) e implementa.

  5. 5

    Conecta el formulario

    Copia la URL de la aplicación web que te otorgó Google y pégala en el panel derecho de esta página.

Código.gs (Apps Script) 
/*
  GOOGLE APPS SCRIPT PARA ALMACENAR AUTOEVALUACIONES
  Este código interceptará el envío del formulario y lo guardará ordenadamente.
*/

function doPost(e) {
  // Configuración de Cabecera CORS para evitar bloqueos del navegador
  var headers = {
    "Access-Control-Allow-Origin": "*",
    "Access-Control-Allow-Methods": "POST, GET, OPTIONS",
    "Access-Control-Allow-Headers": "Content-Type"
  };

  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Preparar encabezados en la primera fila si está vacía
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Marca temporal", 
        "Nombre del Estudiante", 
        "Correo Electrónico", 
        "Grupo / Curso", 
        "Calificación (Estrellas)", 
        "Retroalimentación / Justificación"
      ]);
      
      // Aplicar formato elegante a la fila de cabecera
      var headerRange = sheet.getRange("A1:F1");
      headerRange.setFontWeight("bold")
                 .setBackgroundColor("#0f766e") // Color Teal-700
                 .setFontColor("#ffffff")
                 .setHorizontalAlignment("center");
      
      sheet.setFrozenRows(1);
    }

    // Parsear los datos entrantes del formulario
    var data = JSON.parse(e.postData.contents);
    
    // Insertar la nueva fila con los datos de evaluación
    sheet.appendRow([
      new Date(), // Genera la marca de tiempo de envío
      data.name,
      data.email,
      data.group,
      Number(data.rating),
      data.comments || "Sin retroalimentación"
    ]);

    // Retornar respuesta de éxito
    return ContentService.createTextOutput(JSON.stringify({ 
      "status": "success", 
      "message": "Autoevaluación registrada con éxito." 
    }))
    .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    // Retornar error si algo sale mal
    return ContentService.createTextOutput(JSON.stringify({ 
      "status": "error", 
      "message": error.toString() 
    }))
    .setMimeType(ContentService.MimeType.JSON);
  }
}

// Habilitar opción preflight OPTIONS para peticiones CORS avanzadas
function doOptions(e) {
  return ContentService.createTextOutput("")
    .setMimeType(ContentService.MimeType.TEXT);
}
